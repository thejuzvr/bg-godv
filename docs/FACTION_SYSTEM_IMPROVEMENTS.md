# Улучшения Системы Фракций

## Обзор

Система фракций была полностью переработана с добавлением автоматического отслеживания рангов, визуальных улучшений и уникальных функций, вдохновленных The Elder Scrolls и другими RPG играми.

---

## 1. ✅ Автоматическое Отслеживание Рангов и Выдача Наград

### Что изменилось:
- **Автоматическая проверка повышения ранга** при пожертвованиях фракции
- **Автоматическая выдача наград** при достижении нового ранга:
  - 🎁 **Предметы** — автоматически добавляются в инвентарь
  - ⚡ **Перки** — автоматически разблокируются
  - 👑 **Титулы** — фиксируются в профиле

### Технические детали:
- Функция `checkAndGrantFactionRankRewards()` в `/server/commands/temple-donation.ts`
- Проверяет старую и новую репутацию
- Выдает награды за все достигнутые ранги
- Предотвращает дублирование наград

---

## 2. ✅ Записи в Хронику при Повышении Ранга

### Что изменилось:
- Новый тип записи в хронике: `faction_rank`
- При достижении нового ранга автоматически создается запись:
  - 📜 Название фракции
  - 🏆 Достигнутый ранг
  - 🎁 Полученные награды
  - 📊 Текущая репутация

### Пример записи:
```
🎉 Герой достиг звания "Соратник" во фракции "Соратники"
Репутация: 150
Получены награды: Небесный стальной меч
```

### Файлы:
- `/src/types/chronicle.ts` — добавлен тип `faction_rank`
- `/server/commands/temple-donation.ts` — логика создания записей

## 4. ✅ Пассивные Бонусы Фракций

### Что добавлено:
Каждая фракция теперь предоставляет уникальные пассивные бонусы при достижении определенного ранга:

#### 🛡️ **Соратники:**
- **Скидка кузнецов** (50+ rep): -10% на услуги кузнецов
- **Боевой клич** (150+ rep): +5% урона спутникам
- **Небесная кузница** (150+ rep): Доступ к уникальной кузнице

#### 🔮 **Коллегия Винтерхолда:**
- **Скидка на заклинания** (50+ rep): -15% на томы
- **Магическая регенерация** (150+ rep): +10% к регенерации магии
- **Аркане** (300+ rep): Доступ к запретной библиотеке

#### 🗡️ **Гильдия воров:**
- **Черный рынок** (50+ rep): -20% на услуги ограды
- **Незаметность** (150+ rep): +15% к избежанию обнаружения
- **Теневая сеть** (300+ rep): Доступ к редким заданиям

#### ⚔️ **Темное Братство:**
- **Контракты убийц** (50+ rep): +25% золота за контракты
- **Смертельный удар** (150+ rep): +15% крит. урона кинжалами
- **Святилище** (150+ rep): Доступ к уникальным заданиям

### Визуализация:
- Специальная секция "Пассивные бонусы" в аккордеоне
- Зеленая подсветка для разблокированных бонусов
- Badge с процентами для числовых бонусов
- Четкое указание требуемой репутации

## 5. ✅ Магазины Фракций

### Что добавлено:
Каждая фракция имеет эксклюзивный магазин с уникальными товарами:

#### Функционал:
- **Эксклюзивные предметы** доступны только членам фракции
- **Динамические скидки** в зависимости от ранга
- **Требования к репутации** для покупки каждого предмета

#### Примеры товаров:

**Соратники:**
- Стальной меч (-10% цена)
- Стальной шлем (-15% при 50+ rep)
- Небесный меч (150+ rep)

**Коллегия Винтерхолда:**
- Зелье маны (-20%)
- Том: Дубовая плоть (-30% при 50+ rep)
- Том: Огненный шар (-25% при 150+ rep)

**Гильдия воров:**
- Отмычки (-50% цена!)
- Капюшон вора (-30% при 50+ rep)
- Зелье невидимости (-20% при 150+ rep)

**Темное Братство:**
- Смертельный яд (-40% при 50+ rep)
- Эльфийский кинжал (-25% при 150+ rep)
- Капюшон Темного Братства (-20% при 300+ rep)

### Визуализация:
- Специальная секция "Магазин фракции" в аккордеоне
- Синяя подсветка для доступных товаров
- Badge со скидками (зеленый цвет)
- Четкое указание доступности
