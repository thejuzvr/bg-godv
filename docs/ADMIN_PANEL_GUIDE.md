# 🛠️ Admin Panel Guide

## Обзор

Новая admin-panel полностью переработана с нуля. Она имеет современный интерфейс, похожий на основное приложение, и включает только полезные функции для управления проектом.

## 📁 Структура

```
/admin
├── page.tsx              # Dashboard с аналитикой
├── layout.tsx            # Layout с sidebar
├── actions.ts            # Server actions для статистики
├── data-manager/         # Управление данными
│   ├── page.tsx
│   └── actions.ts
├── telegram/             # Настройки Telegram Bot
│   └── page.tsx
├── drizzle-studio/       # Интеграция Drizzle Studio
│   └── page.tsx
└── test-utils/           # Утилиты для тестирования
    ├── page.tsx
    └── actions.ts
```

## 🎯 Основные разделы

### 1. Dashboard (`/admin`)

**Что показывает:**
- Общая статистика проекта
- Количество пользователей и активных пользователей
- Количество героев, средний и максимальный уровень
- Telegram подписки
- События за последние 24 часа
- Смерти и сражения
- Последние 10 созданных героев

**Особенности:**
- Автоматическое обновление каждые 30 секунд
- Карточки с быстрым доступом к другим разделам
- Современный дизайн с иконками

### 2. Data Manager (`/admin/data-manager`)

**Функционал:**
- **Вкладка "Пользователи":**
  - Просмотр всех пользователей
  - Поиск по email
  - Информация о последнем входе
  - Удаление пользователей (кроме админов)
  - Автообновление списка

- **Вкладка "Герои":**
  - Просмотр всех героев
  - Поиск по имени
  - Информация: имя, уровень, раса, класс
  - Удаление героев с подтверждением
  - Каскадное удаление (летопись, события)

**Server Actions:**
```typescript
fetchAllUsers()          // Получить всех пользователей
fetchAllCharacters()     // Получить всех героев
deleteUser(userId)       // Удалить пользователя
deleteCharacter(charId)  // Удалить героя
```

### 3. Telegram Bot (`/admin/telegram`)

**Функционал:**
- Просмотр всех подписок
- Информация: User, Chat ID, Mode, Last sent
- Включение/выключение подписок через Switch
- Автоматическое обновление данных

**Server Actions:**
```typescript
fetchTelegramSubscriptions()  // Получить все подписки
setTelegramSubscriptionActive(id, active)  // Вкл/выкл подписку
```

### 4. Drizzle Studio (`/admin/drizzle-studio`)

**Что это:**
- Интеграция профессионального редактора БД
- Веб-интерфейс для работы с Postgres

**Возможности:**
- Просмотр и редактирование всех таблиц
- Выполнение SQL-запросов
- Визуализация связей
- Фильтрация и сортировка
- Экспорт/импорт данных
- История миграций

**Как запустить:**
```bash
npm run db:studio
```

После запуска доступен по адресу: https://local.drizzle.studio

**Важно:** 
- Drizzle Studio использует специальный домен `local.drizzle.studio`
- Откройте его в браузере ПОСЛЕ запуска команды
- Порт по умолчанию: 4983

### 5. Test Utils (`/admin/test-utils`)

**Функционал:**

1. **Телепорт в Вайтран** - переместить героя в Вайтран с полным HP
2. **Восстановить здоровье** - восстановить HP до максимума
3. **Сбросить состояние** - полный сброс (бой, смерть, эффекты, локация)
4. **Очистить бой** - удалить текущий бой, установить статус idle
5. **Добавить золото** - добавить указанное количество золота
6. **Тест AI тика** - запустить один тик AI

**Server Actions:**
```typescript
fixCharacterState(userId)              // Полный сброс состояния
resetCharacterToWhiterun(userId)       // Телепорт в Вайтран
healCharacter(userId)                  // Восстановление HP
addGoldToCharacter(userId, amount)     // Добавить золото
clearCharacterCombat(userId)           // Очистить бой
testAITick(userId)                     // Тест AI тика
```

**Особенности:**
- Можно указать ID любого персонажа
- По умолчанию используется ID текущего пользователя
- Все действия с подтверждением через toast

## 🔒 Безопасность

Все страницы админки защищены:
```typescript
const { user, loading } = useAuth(true);

if (!user || !user.isAdmin) {
  return <AccessDenied />;
}
```

Только пользователи с `isAdmin: true` могут получить доступ.

## 📊 Server Actions

Все server actions помечены `"use server"` и возвращают стандартный формат:

```typescript
type ActionResult = {
  success: boolean;
  data?: any;
  message?: string;
  error?: string;
};
```

## 📝 Использование

### Быстрый старт

1. Откройте `/admin`
2. Посмотрите статистику проекта
3. Перейдите в нужный раздел через sidebar или карточки

### Управление пользователями

1. Откройте `/admin/data-manager`
2. Перейдите на вкладку "Пользователи"
3. Используйте поиск для быстрого поиска
4. Нажмите "Удалить" для удаления пользователя

### Управление героями

1. Откройте `/admin/data-manager`
2. Перейдите на вкладку "Герои"
3. Используйте поиск по имени
4. Нажмите "Удалить" для удаления героя (удаляется вся летопись)

### Работа с БД через Drizzle Studio

1. Откройте терминал
2. Выполните `npm run db:studio`
3. Откройте `/admin/drizzle-studio`
4. Нажмите "Открыть Drizzle Studio"

### Тестирование и отладка

1. Откройте `/admin/test-utils`
2. Укажите ID героя (или оставьте пустым)
3. Используйте нужную функцию
4. Получите toast-уведомление о результате

## 🔧 Расширение функционала

### Добавление нового раздела

1. Создайте папку `/admin/new-section/`
2. Добавьте `page.tsx` и `actions.ts`
3. Обновите `adminNavItems` в `layout.tsx`:

```typescript
const adminNavItems = [
  // ... existing items
  { href: '/admin/new-section', icon: YourIcon, label: 'New Section' },
];
```

### Добавление новой утилиты в Test Utils

1. Откройте `/admin/test-utils/actions.ts`
2. Добавьте новую server action:

```typescript
export async function yourNewFunction(userId: string): Promise<TestResult> {
  // ... implementation
  return { success: true, message: "Done!" };
}
```

3. Обновите `/admin/test-utils/page.tsx` с новой кнопкой

## 💡 Советы

- **Статистика обновляется автоматически** - не нужно постоянно обновлять страницу
- **Используйте Drizzle Studio** для сложных операций с БД
- **Test Utils полезны** для отладки и тестирования
- **Все действия логируются** - проверяйте server logs при ошибках
- **Создавайте бэкапы** перед массовым удалением данных
