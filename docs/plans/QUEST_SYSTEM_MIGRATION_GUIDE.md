## 📊 Схема работы новой системы

### Приоритизация заданий

```
Urgent (type='urgent')     → priority = 90
Main (type='main')         → priority = 70
Bounty (type='bounty')     → priority = 60
Side (type='side')         → priority = 40
```

### Логика AI

```
1. Проверить: Есть ли is_active квест?
   ├─ ДА → Продолжить его выполнение
   └─ НЕТ ↓

2. Проверить: Есть ли in-progress квесты?
   ├─ ДА → Выбрать с наивысшим priority, сделать активным
   └─ НЕТ ↓

3. Создать новый квест из доступных шаблонов
   └─ Установить как активный
```

### Божественное вмешательство

Игрок может в любой момент:
1. Открыть Журнал заданий
2. Выбрать любое in-progress задание
3. Нажать "Сделать активным"
4. Герой переключится на это задание

## 🧪 Тестовые сценарии

### Сценарий 1: Создание нового персонажа
1. Создать персонажа
2. Дождаться, пока AI возьмёт первый квест
3. Проверить, что квест появился в Dashboard и помечен как активный
4. Проверить, что квест отображается в Журнале заданий

### Сценарий 2: Множественные квесты
1. Взять несколько квестов (через старую систему или API)
2. Проверить, что только один помечен как активный
3. Проверить вкладку "В процессе" - должны быть неактивные квесты
4. Установить другой квест активным
5. Проверить, что AI переключился на него

### Сценарий 3: Завершение квеста
1. Дождаться завершения активного квеста
2. Проверить, что награды получены
3. Проверить, что автоматически выбран следующий квест (если есть)
4. Проверить, что завершённый квест в соответствующей вкладке

### Сценарий 4: Progress Bar
1. Взять многозадачный квест (с подзадачами)
2. Проверить отображение подзадач в Dashboard
3. По мере выполнения проверять обновление прогресса
4. Проверить, что прогресс рассчитывается корректно
