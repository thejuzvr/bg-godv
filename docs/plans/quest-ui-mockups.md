## 6. Система приоритетов (визуальная)

```
Приоритет задания отображается звёздами:

★★★★★ (81-100) - Критический приоритет (срочные/основные квесты)
★★★★☆ (61-80)  - Высокий приоритет
★★★☆☆ (41-60)  - Средний приоритет (стандартные квесты)
★★☆☆☆ (21-40)  - Низкий приоритет
★☆☆☆☆ (0-20)   - Очень низкий приоритет (развлекательные квесты)
```

## 7. Цветовая схема

```
🟢 Зелёный    - Доступные задания, можно принять
🔵 Синий      - Задания в процессе, не активные
🟡 Жёлтый     - Активное задание (текущий фокус)
🔴 Красный    - Проваленные задания / истекающий срок
⚪ Серый      - Завершённые задания
🔒 Замок      - Заблокированные (не хватает уровня/репутации)
```

## 9. Анимации и переходы

### При смене активного задания:
```
1. Старое активное задание: 🎯 → 📋 (плавное изменение иконки)
2. Новое активное задание: 📋 → 🎯 (плавное появление)
3. Transition: 300ms ease-in-out
4. Progress bar: пульсация при обновлении (200ms)
```

### При завершении подзадачи:
```
1. Status icon: ⚙️ → ✅ (плавное изменение + увеличение на 120% на 200ms)
2. Progress bar: плавное заполнение (500ms ease-out)
3. Зелёная вспышка на фоне подзадачи (300ms fade-out)
```
