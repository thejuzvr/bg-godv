## 🎮 Игровая механика

### Цикл опасности:
1. **Начало:** Окраина имеет уровень опасности 20-50%
2. **Бой:** Герой побеждает врага → опасность -5-10%
3. **Визуализация:** Изменение отображается на карте
4. **Регенерация:** Опасность медленно восстанавливается со временем*

*Примечание: Регенерация требует интеграции с worker'ом (опционально)

### Добыча ресурсов:
1. Перейти на окраину (*_outskirts)
2. Открыть страницу "Добыча ресурсов"
3. Потратить 10 выносливости → получить случайное количество ресурса
4. Различные ресурсы в зависимости от локации
