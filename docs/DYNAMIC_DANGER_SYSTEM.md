# 🎲 Динамическая система уровня опасности

## Обзор

Теперь уровень опасности локаций **изменяется в реальном времени** в зависимости от:
- ⏰ Времени суток
- 🍂 Сезона
- 🌧️ Погоды
- 🗺️ Активности игрока

## ✅ Что реализовано

### 1. Динамические модификаторы опасности

**Файл:** `src/lib/danger-level-manager.ts`

#### Время суток
- 🌙 **Ночь**: +20% опасности
- 🌆 **Вечер**: +10% опасности
- 🌅 **Утро**: -5% опасности
- ☀️ **День**: -10% опасности

#### Сезон
- ❄️ **Зима**: +15% (голодные звери)
- 🍂 **Осень**: +5%
- 🌸 **Весна**: -5%
- ☀️ **Лето**: 0%

#### Погода
- 🌨️ **Снег**: +20% (метель опасна)
- 🌫️ **Туман**: +15% (плохая видимость)
- 🌧️ **Дождь**: +5%
- ☁️ **Облачно**: 0%
- ☀️ **Ясно**: -5%

#### Активность игрока
- 📍 **Текущая локация**: -20% (герой здесь, безопаснее)
- 🕐 **Недавнее посещение** (< 24 часа): -15%
- ✓ **Была в посещённых**: -5%
- ❓ **Неизвестная локация**: +10%

### 2. Формула расчёта

```typescript
currentDanger = baseDanger + 
                timeOfDayModifier + 
                seasonModifier + 
                weatherModifier + 
                playerActivityModifier

// Ограничение: 0-100%
```

### 3. Примеры расчётов

**Окрестности Вайтрана (базовая опасность: 25%)**

| Условия | Расчёт | Итог |
|---------|--------|------|
| День, Лето, Ясно, Посещал | 25 - 10 + 0 - 5 - 5 = **5%** ⬇️ | Безопасно |
| Ночь, Зима, Метель, Неизвестно | 25 + 20 + 15 + 20 + 10 = **90%** ⬆️ | Очень опасно! |
| Вечер, Осень, Дождь, Здесь | 25 + 10 + 5 + 5 - 20 = **25%** ➡️ | Умеренно |

**Окрестности Винтерхолда (базовая опасность: 50%)**

| Условия | Расчёт | Итог |
|---------|--------|------|
| День, Лето, Ясно, Посещал | 50 - 10 + 0 - 5 - 5 = **30%** ⬇️ | Умеренно |
| Ночь, Зима, Туман, Неизвестно | 50 + 20 + 15 + 15 + 10 = **110 → 100%** ⬆️ | МАКС! |

## 🎨 Визуализация

### На карте

**Зоны опасности** (для `outskirts` типа):
- Круг диаметром 260px
- Цвет меняется в реальном времени:
  - 🟢 0-19%: Зелёный
  - 🟡 20-39%: Жёлтый
  - 🟠 40-69%: Оранжевый
  - 🔴 70-100%: Красный

### В модальном окне

**Показывается:**
1. **Текущий уровень**: с цветовым индикатором
2. **Тренд**: 📈 растёт | 📉 падает | ➡️ стабильно
3. **Базовый уровень**: если отличается от текущего
4. **Пояснение**: "повышено/снижено из-за условий"

**Пример:**
```
Опасность
45% Опасно 📈

Базовый уровень: 25% (повышено из-за условий)
```

## 🎮 Игровая механика

### Влияние на геймплей

1. **Шанс встреч**
   - Высокая опасность = больше врагов
   - Используется в `processTravelEvents()`

2. **Планирование путешествий**
   - Игроки видят когда лучше идти
   - Днём безопаснее, ночью опаснее

3. **Прогрессия**
   - Посещённые локации становятся безопаснее
   - Мотивация исследовать

### Стратегии игрока

**Для безопасных путешествий:**
- ☀️ Путешествовать днём
- 🌞 В ясную погоду
- 🗺️ Посещать локации повторно (они становятся безопаснее)

**Для хардкорных игроков:**
- 🌙 Путешествовать ночью (риск/награда)
- ❄️ Зимой в метель
- ❓ В неизвестные места

## 💻 Техническая реализация

### Интеграция

**В `src/app/dashboard/map/page.tsx`:**

```typescript
// Apply dynamic danger levels
const locationsWithDynamicDanger = useMemo(() => {
  return applyDynamicDangerToLocations(gameData.locations, {
    timeOfDay: character.timeOfDay,
    season: character.season,
    weather: character.weather,
    visitedLocations: character.visitedLocations,
    currentLocation: character.location
  });
}, [gameData, character]);
```

### Производительность

- ✅ Используется `useMemo` для кэширования
- ✅ Пересчитывается только при изменении условий
- ✅ Лёгкие математические операции
- ✅ Не нагружает сервер (клиентский расчёт)

### API функций

```typescript
// Рассчитать динамическую опасность для одной локации
calculateDynamicDanger(location, context): DynamicDangerInfo

// Применить ко всем локациям
applyDynamicDangerToLocations(locations, context): Location[]

// Получить цветовую схему
getDangerColor(dangerLevel): ColorScheme

// Форматировать модификаторы для UI
formatDangerModifiers(modifiers): string[]
```

## 📊 Балансировка

### Текущие значения

**Безопасные локации** (города, поселения):
- Не меняют опасность (всегда 0%)

**Опасные локации** (окрестности, руины, подземелья):
- Базовая: 20-70%
- С модификаторами: 0-100%

### Лимиты

- **Минимум**: 0% (не может быть отрицательным)
- **Максимум**: 100% (не может превысить)
