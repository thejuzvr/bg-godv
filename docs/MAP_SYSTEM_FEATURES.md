# Система карты мира - Новые возможности

## Обзор

Была реализована полноценная система исследования мира с погодными условиями, открытием локаций и динамическими путешествиями. Система добавляет глубину геймплея и создаёт живой, интерактивный мир.

## 🗺️ Основные возможности

### 1. Система открытия локаций

**Статусы локаций:**
- **Открытые** - Стартовые города и посещённые ранее локации
  - Отображаются с иконками и полной информацией
  - Быстрое перемещение (нормальная скорость)
  - Безопасные маршруты с минимальным риском

- **Неоткрытые** - Неизведанные территории
  - Отображаются как "???" с пунктирной границей
  - Медленное перемещение (x2.5 дольше)
  - Высокий шанс случайных встреч и событий
  - Автоматически открываются при первом посещении

**Стартовые локации** (открыты с начала игры):
- Все крупные города: Солитьюд, Виндхельм, Вайтран, Маркарт, Рифтен
- Малые города: Данстар, Винтерхолд, Морфал, Фолкрит

**Требуют открытия:**
- Окрестности городов
- Деревни (Ривервуд, Айварстед, Рорикстед)
- Руины и подземелья

### 2. Погодная система на карте

**HUD погоды** отображает:
- Текущие погодные условия
- Влияние на скорость путешествия
- Предупреждения о рисках

**Погодные модификаторы:**
- ☀️ **Ясно** / **Облачно**: нормальная скорость (x1.0)
- 🌧️ **Дождь**: замедление на 20% (x1.2)
- ❄️ **Снег**: замедление на 30% (x1.3)
- 🌫️ **Туман**: замедление на 25% (x1.25)

### 3. Расчёт времени путешествия

**Формула:**
```
Время = Базовое расстояние × Погодный модификатор × Модификатор открытия
```

**Параметры:**
- **Базовое расстояние**: зависит от типа локации (50-200 единиц)
- **Погодный модификатор**: 1.0-1.3 (см. выше)
- **Модификатор открытия**: 
  - Открытая локация: x1.0
  - Неоткрытая локация: x2.5

**Примеры:**
- Вайтран → Солитьюд (открыто, ясно): ~2.5 часа
- Вайтран → Окрестности (неоткрыто, снег): ~4 часа
- Солитьюд → Руины (неоткрыто, дождь): ~5.5 часов

### 4. Система случайных встреч

**Для неоткрытых локаций:**

Шанс встречи увеличивается на:
- +30% за неизведанность
- +20% за высокий уровень опасности локации
- +15% за дождь/снег
- +10% за туман

**Типы событий:**

**Враждебные встречи** (35-60% шанс):
- Засада бандитов
- Стая волков
- Дикие медведи
- Патруль скелетов

**Опасности** (15-20% шанс):
- Древние ловушки (10-25 урона)
- Ядовитые растения (отравление)

**Находки** (10-15% шанс):
- Скрытые тайники (30-80 золота)
- Древние святилища (временные баффы)
- Встреча с дружелюбным путником

**Нарративные события** (15-25% шанс):
- Таинственные руины
- Странные следы
- Потерянная тропа
- Прекрасные виды

### 5. Интерактивная карта

**Возможности:**
- ✅ Full-screen режим без прокрутки страницы
- ✅ Zoom (приближение/отдаление) с помощью кнопок или колеса мыши
- ✅ Pan (перемещение по карте) перетаскиванием
- ✅ Оптимизация рендеринга (видимые локации)
- ✅ Адаптивный размер маркеров при зуме

**Визуализация:**
- 🏰 Открытые локации - яркие иконки, цветные границы
- ❓ Неоткрытые - знак вопроса, пунктирная граница, полупрозрачность
- 🎯 Текущая локация - пульсирующая анимация
- ⚠️ Уровни опасности - цветные индикаторы (зелёный → жёлтый → оранжевый → красный)

### 6. Детальная информация о локациях

**Модальное окно** показывает:
- Название и тип локации
- Уровень опасности
- Описание (изменяется для неоткрытых)
- Расчётное время в пути
- Предупреждения:
  - Неизведанная территория
  - Погодные условия
  - Уровень опасности
  - Риск встреч

## 🎮 Геймплей

### Рекомендации для игроков

1. **Планируйте путешествия** - проверяйте погоду перед дальними поездками
2. **Исследуйте постепенно** - начните с близких неоткрытых локаций
3. **Готовьтесь к встречам** - берите зелья и еду для опасных маршрутов
4. **Используйте погоду** - ясная погода лучше для открытия новых мест
5. **Изучайте карту** - приближайте и исследуйте новые области

### Влияние на прогрессию

- Открытие локаций даёт постоянный прогресс
- Первое посещение добавляет локацию в список открытых
- Повторные путешествия становятся быстрее
- Риски снижаются с открытием территории

## 📊 Балансировка

**Базовые расстояния:**
- Крупные города: 120-200 единиц (2-3.5 часа)
- Малые города: 130-160 единиц (2-2.5 часа)
- Деревни: 80-90 единиц (1.5-2 часа)
- Окрестности: 50-80 единиц (1-1.5 часа)
- Руины/подземелья: 110-120 единиц (2-2.5 часа)

**Шансы событий (неоткрытые локации):**
- Враждебные встречи: 35-60%
- Опасности: 15-20%
- Находки: 10-15%
- Нарративы: 15-25%

## 🐛 Известные ограничения

1. События генерируются только для активных путешествий
2. Погода не влияет на уже начатое путешествие
3. Нет визуального пути между локациями
4. Все локации видны на карте (даже неоткрытые)
