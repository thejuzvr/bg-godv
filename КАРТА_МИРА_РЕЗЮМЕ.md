## 🎮 Как это работает

### Открытие локаций
1. Игрок видит неоткрытую локацию как "???"
2. При нажатии показывается время в пути (увеличено x2.5)
3. Путешествие идёт дольше, с высоким шансом встреч
4. При прибытии локация автоматически открывается
5. Повторные путешествия быстрее и безопаснее

### Влияние погоды
- **Ясно/Облачно**: нормально
- **Дождь**: +20% времени
- **Снег**: +30% времени
- **Туман**: +25% времени

### Примеры путешествий
```
Вайтран → Солитьюд (открыто, ясно)
  Время: ~2.5 часа
  Риск: низкий

Вайтран → Окрестности (неоткрыто, снег)
  Время: ~4 часа  
  Риск: высокий (возможны волки, бандиты)

Солитьюд → Руины (неоткрыто, туман)
  Время: ~5.5 часов
  Риск: очень высокий (ловушки, скелеты)
```
