# ElderScrollsIdle: Idle RPG

## Описание проекта

ElderScrollsIdle — это idle RPG во вселенной The Elder Scrolls, где игроки наблюдают за развитием своего персонажа, а не управляют им напрямую. Игра использует систему принятия решений на основе взвешенного рандома, что создает живое повествование. Герой самостоятельно исследует Скайрим, выполняет квесты, сражается и взаимодействует с NPC.

**Ключевые особенности:**
- **Offline Mode**: Персонаж продолжает жить и развиваться, даже когда вы не в сети.
- **AI Brain**: Умная система принятия решений на основе состояния персонажа (здоровье, инвентарь, местоположение).
- **NPC Social System**: Система отношений с уникальными персонажами.
- **Масштабный контент**: Сотни предметов, квестов и уникальных мыслей персонажа, включая фанатские мемы.

## Установка

1. **Клонируйте репозиторий.**

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Настройте окружение:**
   Скопируйте `env.example` в новый файл `.env` и заполните необходимые переменные:
   - `DATABASE_URL`: Подключение к PostgreSQL.
   - `REDIS_URL`: Подключение к Redis (используется для BullMQ и Socket.IO).
   - Остальные параметры согласно комментариям в `env.example`.

4. **Подготовьте базу данных:**
   Примените схему Drizzle к вашей базе данных:
   ```bash
   npm run db:push
   ```

## Запуск

### Быстрый запуск (все компоненты)
Запускает одновременно Next.js, фоновый воркер и realtime сервер:
```bash
npm run dev:all
```

### Раздельный запуск компонентов
Если вам нужно запустить части проекта по отдельности:

- **Frontend/API (Next.js):**
  ```bash
  npm run dev
  ```
- **Background Worker (обработка логики в фоне):**
  ```bash
  npm run worker
  ```
- **Realtime Server (Socket.IO):**
  ```bash
  npm run realtime
  ```
