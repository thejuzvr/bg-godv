## 3. ✅ RPG Элементы

### Категоризация предметов:
Каждый предмет автоматически категоризируется по префиксу ID:

| Категория | Префикс | Иконка | Цвет |
|-----------|---------|--------|------|
| Руды | `ore_` | 💎 Gem | Янтарный |
| Зелья | `potion_` | ✨ Sparkles | Фиолетовый |
| Оружие | `weapon_` | ⚔️ Sword | Красный |
| Броня | `armor_` | 🛡️ Shield | Синий |
| Свитки | `scroll_` | 📜 Scroll | Индиго |
| Разное | остальные | 📦 Package | Серый |

### Система трендов:
Динамическая система определения популярности товара:
- **Ratio = Спрос / Предложение**
- Ratio > 1.2 → **Растет** (высокий спрос)
- Ratio < 0.8 → **Падает** (низкий спрос)
- Иначе → **Стабильно**

### Визуальная иерархия:
- **Важная информация** — крупнее и ярче
- **Второстепенная** — меньше и приглушеннее
- **Интерактивные элементы** — четко выделены
- **Состояния** — disabled элементы визуально отличаются
